# 🧮 CodeAlpha Calculator

A modern, responsive basic calculator built using HTML, CSS, and JavaScript as part of the CodeAlpha Frontend Development Internship.

## 📌 Project Overview

This project is a web-based calculator designed with a clean and modern user interface. It performs basic arithmetic calculations and provides additional features such as percentage calculation, positive/negative number conversion, delete functionality, and keyboard support.

## ✨ Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal calculations
- Percentage calculation
- Positive/negative number conversion
- Clear all functionality
- Delete/backspace functionality
- Real-time display
- Keyboard support
- Division-by-zero error handling
- Responsive design
- Smooth button animations
- Modern user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## ➕ Supported Operations

The calculator supports:

| Operation | Symbol |
|---|---|
| Addition | + |
| Subtraction | − |
| Multiplication | × |
| Division | ÷ |
| Percentage | % |
| Decimal | . |
| Positive/Negative | +/− |

## ⌨️ Keyboard Controls

The calculator can also be operated using the keyboard.

| Key | Action |
|---|---|
| 0–9 | Enter numbers |
| + | Addition |
| - | Subtraction |
| * | Multiplication |
| / | Division |
| Enter | Calculate result |
| Backspace | Delete last digit |
| Escape | Clear calculator |
| . | Decimal point |
| % | Percentage |
